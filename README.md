# beancli

beancli is a CLI argument parser for Zig where the struct declaration is the whole CLI.

## Features
- [] Struct-defined CLI
- [] Boolean switches
- [] Long flags (`--flag`)
- [] Short flags (`-f`)
- [] String values
- [] Int and Float fields
- [] Enum fields
- [] Positional
- [] Rest field
- [] Commands
- [] Subcommands
- [] `--flag=value` syntax
- [] `--` barrier
- [] Counted flags `-fff`
- [] Short flag clusters `-fvp8080`
- [] Repeated options `--file 1` `--file 2`
- [] Error diagnostics
- [] Help text
- [] Did-you-mean suggestions
- [] Environment variables
- [] Shell completions
